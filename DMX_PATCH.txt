================================================================================
SUNLITE SUITE IMPORT INSTRUCTIONS
================================================================================

1. Open Sunlite Suite
2. Go to: Fixture > Patch / Scan Library
3. For each fixture, click "Add Fixture"
4. Search for:
   - "Ayra ERO Micro Spot LED" (add 2 of these)
   - "Ayra ERO Micro Beam FX" (add 2 of these)
   - "Cameo THUNDER WASH 100" (add 1 of these)
5. Set DMX addresses as listed above
6. Verify in the Matrix View that all 5 fixtures are patched correctly
7. Test each fixture individually to confirm DMX communication

================================================================================
DASLIGHT IMPORT INSTRUCTIONS
================================================================================

1. Open Daslight
2. Go to: Scan Library or Patch
3. Click "Add Fixture" for each device
4. Search manufacturer and model:
   - Ayra > ERO Micro Spot LED
   - Ayra > ERO Micro Beam FX
   - Cameo > THUNDER WASH 100
5. Set DMX Start Address for each:
   - Spot 1: 1
   - Spot 2: 17
   - Beam FX 1: 33
   - Beam FX 2: 49
   - Cameo: 65
6. Arrange fixtures in the 3D Visualizer if desired
7. Test output by moving each fixture manually in Live Mode

NOTES & BEST PRACTICES
================================================================================

1. Universe: This patch uses only DMX Universe 1 (channels 1-512)
2. Headroom: You have plenty of unused channels (69-512) for future expansion
3. Movement Speed: Set fixture pan/tilt speed to FAST for club/techno shows
4. Beam Width: Keep Beam FX at tight/narrow setting for maximum impact
5. Color Accuracy: Test RGB colors before the show (white balance)
6. Strobe Safety: Use strobe responsibly; check venue frequency regulations
7. Backup: Save your patch file after every change
