================================================================================
HOW TO IMPORT INTO SUNLITE SUITE
================================================================================

1. Open Sunlite Suite
2. Go to: View > Scenes (or press Scenes tab)
3. Create a new scene for each cue:
   - Right-click > New Scene
   - Name it: "CUE 01 - Build / Blackout"
   - Set fixture intensities and colors as listed
   - Save

4. Create a Chase or Timeline:
   - Go to: Chases > New Chase
   - Add scenes in order (CUE 01, CUE 02, etc.)
   - Set fade times and step duration
   - Enable AutoStep with timing as shown

5. Timing adjustment:
   - Each cue should run for 7.5 seconds (hold time)
   - Set fade time as specified per cue

6. Test in Live mode before show

================================================================================
HOW TO IMPORT INTO DASLIGHT
================================================================================

1. Open Daslight
2. Create Scenes (cues):
   - Go to: Step/Scene window
   - New Scene for each CUE
   - Name it: "CUE 01 - Build"
   - Adjust all fixtures to settings listed
   - Save

3. Build a Chase:
   - Go to: Chaselist
   - New Chase
   - Add all 14 scenes in order
   - Enable AutoStep

4. Set Timing:
   - Step Duration: 7.5 seconds per cue
   - Fade Time: As listed for each cue
   - Tempo: Sync to 128 BPM if available

5. Test in Live Mode
6. Export as .d3s file for backup
